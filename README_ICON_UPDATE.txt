ATHARV ENTERPRISES — CUSTOM APP ICON UPDATE

This updated Android project uses the supplied Atharv Enterprises logo as the launcher icon.

GitHub mobile steps:
1. Open ATHARV-ENTERPRISES repository.
2. Upload this ZIP to the repository root, replacing the existing atharv-android-project.zip. Keep the exact same filename.
3. Commit the upload.
4. Open Actions and wait for Build Atharv Android APKs to succeed.
5. Open the run, download Atharv-Enterprises-APKs, extract it, and install the new APK.

Before replacing the installed app, export a JSON backup. If Android still shows the old icon, restart the launcher or phone.

IMPORTANT: in-place installation requires the same signing key as the installed APK. Keep the CI signing key consistent; do not regenerate it between builds.
