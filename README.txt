ATHARV ENTERPRISES — OFFLINE-FIRST ROAD CONTRACT MANAGEMENT

Included: Dashboard, seeded UP PWD contract, Projects, MB, DPR, Labour Attendance, Material Purchases, Consumption, minimum-stock alerts, Expenses, Payment Register, Contractor/RA Bill calculator (GST/TDS/retention/advance/other deductions), Machinery, project-wise expense/margin/received/pending reports, GPS-tagged site evidence, photos, drawn signature capture, Document Vault, JSON backup/restore, CSV export and Print/Save PDF.

DATA: Stored locally in this browser/app storage. Export JSON backups frequently. Photos, signatures and uploaded documents are stored as local data and can consume substantial device storage.

INSTALL AS PWA: This folder must be hosted on an HTTPS website (or localhost). Open index.html through that HTTPS address in Chrome on Android, then use Chrome menu > Install app / Add to Home screen. Service worker enables offline loading after first visit.

ANDROID APK: This deliverable is the completed offline web app/PWA package, NOT a compiled APK. A signed APK requires Android SDK/Gradle build tooling and Android WebView wrapper build/signing; those tools are not present in this build environment. Do not rename the ZIP to .apk.

IMPORTANT LIMITATIONS: GPS accuracy and device time depend on phone settings and permissions; timestamps are not tamper-proof forensic proof. Drawn signature is an image acknowledgment, not a legally certified digital signature/eSign. MB/DPR and payment calculations are management aids; verify official PWD formats, agreement clauses, tax treatment and bill deductions before submission.
